# 本地数据目录

该目录的真实采集样本、运行时导入数据、偏移研究结果和用户环境元数据不进入源码仓库。

需要在新环境准备数据时，应通过受控制品存储或脱敏导出流程完成，并至少满足：

- 不包含账号、角色名、聊天内容、窗口标题、PID、绝对本机路径或访问令牌；
- 每类数据带版本、来源、许可、哈希和兼容客户端版本；
- 训练集、验证集与运行时配置分开存放；
- 导入前验证签名或 SHA-256，导入后不自动回传；
- 如需远程存储，使用私有存储桶和最小权限临时凭据，不使用公开读写桶。

仓库只保留本说明文件。需要公开的示例数据应另行生成最小化、脱敏的 `*.example` 文件并接受审查。
