# 待开发（Pending Work）

本目录存放 **尚未完成** 的任务书 / 设计方案，供 Codex 或其他执行方直接开工。

## 使用规则（强制）

1. **新任务**：在本目录新建独立 `.md` 任务书（建议命名：`主题_YYYYMMDD.md`）。
2. **进行中**：任务书文首 `状态` 字段保持为 `待开发` 或 `进行中`。
3. **任务完成（必须）**：
   - 将任务书文首 **状态** 改为 **`已完成`**；
   - 在任务书内 **逐条勾选** 验收标准 / 阶段 checklist（`- [ ]` → `- [x]`）；
   - 填写 **完成日期、完成人/代理、交付路径摘要**；
   - 不得只口头说完成而不改 MD。
4. **部分完成**：状态改为 `部分完成`，并在文档中标明未完成条目与阻塞原因。
5. **取消/废弃**：状态改为 `已取消`，写明原因；文件可保留备查。
