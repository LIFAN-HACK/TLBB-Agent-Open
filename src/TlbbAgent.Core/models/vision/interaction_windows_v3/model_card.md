## 推理契约

- 输入：完整游戏客户区 RGB 图像，保持宽高比做 letterbox。
- 推荐推理尺寸：`960`。
- 最低置信阈值：`0.75`。
- NMS IoU：`0.70`。
- 输出坐标必须逆变换回原始客户区像素。
- 相同类别连续两帧稳定后才能向 L2 暴露 crop；低置信、越界、严重遮挡返回 `unknown/noop`。
- L2 必须在 L1 crop 内确认按钮、页签和格子。不得只按 L1 框比例直接点击。

## 验证结果

- 训练数据：568 张；训练/验证/测试为 `485/29/54`。
- 原生正向测试：54 张、104 个窗口、`TP=104 / FP=0 / FN=0`。
- 独立纯负样本：50 张、`FP=0`。
- ONNX 与 PyTorch 的 54 张逐图匹配数完全一致；最大坐标差 `0.018 px`，最大置信度差 `0.000273`。
- 正向测试分辨率覆盖：`785x617`、`799x1385`、`986x1375`、`2559x1436`、`2559x1439`、`2560x1369`、`2576x1408`。
- 测试 mAP50：`0.9950`；mAP50-95：`0.9868`。

## 已知边界

- 月卡和银行只有单一采集会话，各自原生测试实例仅 1 个，仍需补独立会话。
- 商店框最差 IoU 为 `0.9134`，单边最大误差约 `28.4 px`；按钮点击必须由 L2 安全框完成。
- 本模型不包含死亡弹窗、确认框、NPC 对话、目的地、自动寻路、角色/宠物面板。
- 本模型不能证明背包物品识别或自动出售已经可用。
