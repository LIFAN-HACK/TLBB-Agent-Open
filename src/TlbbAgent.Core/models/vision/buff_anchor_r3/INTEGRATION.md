# Buff 首行锚点 L1 候选模型 r3

## 作用

`buff_anchor_detect.onnx` 只定位屏幕上真实可见的 Buff 第一行外框，类别只有 `buff_anchor_row`。
它不是 Buff 身份、坐骑状态或冷却判断模型；这些信息由 L2 在 L1 crop 内识别。

## 接入

1. 全屏截图按 YOLO letterbox 缩放到 `1280x1280`，RGB、NCHW、float32、除以 255。
2. 解码输出 `[1,5,33600]`，推荐置信度阈值 `0.50`、NMS IoU `0.50`。
3. 使用 letterbox 的比例和 padding 把框还原到原始截图像素坐标。
4. 无框或低置信度时返回 `absent/unknown`，禁止点击。
5. L2 以该框为锚点，按真实图标边缘校准槽距，再扫描最多 6 列、5 行；不要把不可见容量区当成检测真值。

## 当前验证

- ONNX：Precision `0.99799`，Recall `1.00000`，mAP50-95 `0.99200`。
- 26 张正样本：0 漏框、0 额外框；最差 IoU `0.94398`；最大四边误差 `3.4 px`。
- 5 张独立世界地图覆盖负样本：PyTorch/ONNX 在 conf 0.05、0.15、0.25 均为 0 误报。

## 限制

- 1659x785 与 2576x1408 的独立测试样本各只有 1 张，不能视为充分跨分辨率覆盖。
- 当前负样本只有 5 张且场景集中在世界地图覆盖。
- 因此产物状态是“可在功能开关下接入验证的候选”，不是全场景运行授权。
