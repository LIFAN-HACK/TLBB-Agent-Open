# 右侧技能栏 L1 V2 双档模型卡

## 1. 结论与状态

本产物是独立的 L1 辅助检测器，用于在完整游戏画面中定位右侧两列技能栏的整体区域，随后由槽位重建逻辑生成最多 `2 x 10` 个技能槽 crop。

- 类别：`right_skill_bar`，类别 ID `0`。
- 当前状态：`ready_for_backend_candidate_integration_not_runtime_deployed`。
- 已完成训练、ONNX 导出和多分辨率离线验证。
- 尚未接入 TLBB Agent 运行时，不能把“模型已训练”表述成“功能已上线”。
- 本模型不识别技能名称、不判断冷却状态，也不决定技能是否允许释放。

ONNX 为固定 batch `1`。运行时必须分别创建 640 和 1280 会话，不能向任一模型传入批量图片。

## 3. 输入预处理与输出解码

预处理应与 Ultralytics YOLOv8 保持一致：

1. 输入为完整游戏客户区画面，不含人为画框或缩略复核页。
2. 按目标输入尺寸等比缩放，使用 letterbox 补边，补边像素值 `114`。
3. BGR 解码图需转换为 RGB。
4. 转为 `NCHW float32`，像素归一化到 `[0, 1]`。
5. 按 YOLOv8 detection 输出格式解码，执行 NMS，再把坐标反映射回原始画面像素。

建议原始候选阈值保留到 `0.001`，NMS IoU 使用 `0.70`，每档最多保留 `20` 个候选；业务接纳阈值和几何门控在双档融合阶段执行。

## 4. 双档融合规则

640 与 1280 两档都在同一原始帧上推理。每个预测框先反映射到原始像素，再执行以下门控：

| 条件 | 接纳范围 |
|---|---:|
| 置信度 | `>= 0.25` |
| 框宽 | `52..105 px` |
| 框高 | `245..440 px` |
| 原图右边缘到框右边缘 | `-6..65 px` |
| 纵向边界 | `y1 >= 0` 且 `y2 <= frame_height + 4` |

从所有通过门控的候选中选择置信度最高者。两档都无合法候选时必须输出 `unknown/unavailable`，不得回退到固定点击坐标。

离线验证基线是“两档都运行后融合”。若后端为性能改成“先 1280，失败再 640”，必须先在完整验收样例上重新跑通，不能直接视为等价。

## 5. 槽位重建

游戏 UI 的槽位是固定像素几何，不随窗口分辨率按比例缩放：

- 列数：`2`
- 预留行数：`10`
- 单槽外框：`32 x 32 px`
- 列距：`44 px`
- 行距：`35 px`
- 完整预留网格：`76 x 347 px`

以检测框左上角附近的首槽锚点 `(x0, y0)` 为基准，第 `row` 行、第 `col` 列的理论区域为：

```text
x = x0 + col * 44
y = y0 + row * 35
w = 32
h = 32

row = 0..9
col = 0..1
```

注意：

1. 不得把模型框的宽高平均切成 `2 x 10`。稀疏技能、底部空槽和画面边界会改变可见包围范围。
2. 模型框是整体区域的近似定位。应在 `(x1, y1)` 周围约 `+-6 px` 内，用 32 px 槽位边框做局部吸附，再应用固定行列间距。
3. 所有槽位必须裁剪到当前游戏客户区边界；越界或边框证据不足的槽位标记为 `unknown`。
4. L2 图标身份、灰罩和 CD 数字判断只能读取单槽 crop，不能直接对全屏或整个技能栏做模板匹配。

## 6. 验证结果

单档 1280 训练测试指标：

- Precision：`1.0000`
- Recall：`0.9654`
- mAP50：`0.9886`
- mAP50-95：`0.9667`

双档 ONNX 业务门控验证：

- V2 独立盲测：`33/33` 检出。
- 全部人工窗口回归：`40/40` 检出。
- 已覆盖 `785x617`、`796x624`、`986x1375`、`1021x792`、`1273x746`、`1275x1050`、`1920x1107`、`2559x1436`、`2559x1439`、`2560x1369`、`2576x1408` 等窗口尺寸。
- 复核图：`review/pages/`；原尺寸代表样本：`review/representative_full/`。

上述结果证明当前测试域内的定位能力，不代表对未采集 UI 皮肤、缩放模式或负样本场景的无条件保证。

## 7. 限制与安全边界

- 17 张遮挡、过渡态或极稀疏不确定图已隔离，未进入训练、验证、测试，也未作为负样本。
- 当前没有独立的大规模纯负样本集，因此源像素几何门控是运行时必需条件。
- 640 档用于较小客户区，1280 档用于标准和大窗口；单独使用任一档都会产生已知漏检。
- L1 只回答“右侧技能栏在哪里”。技能身份、CD、可释放策略和点击动作必须由 L2 与状态机分别负责。
- 任一阶段低置信、越界、身份不明、CD 不明或策略不允许时，最终动作必须为 `noop`。
