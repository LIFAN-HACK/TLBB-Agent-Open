# 目标数据目录

该目录只保存可追溯的目标名称数据，不保存旧授权、账号或运行库。

- `monster/maps/`：官网资料站同步的 34 个地图、254 个敌人名称；由 `tools/Sync-OfficialMonsterCatalog.ps1` 生成。
- `boss/official/`：官方资料站公开的 BOSS 数据。
- `boss/safety/`：默认禁止攻击的召唤物、跟班或机制目标。
- `player/`：玩家目标策略；默认关闭，不预置可攻击玩家。

每条数据必须包含来源。未经核实的名称不得进入内置默认规则。

官网同步数据只作为名称目录，不会自动覆盖玩家规则；内置禁止攻击条目始终优先于允许条目。
