# 给后端开发：小地图标记语义与状态机修正

## 必须修正的错误假设

不能再使用“检测到黄色/橙色图形 = 附近有怪”和“单帧无黄点 = 附近无怪”。新增实测确认小地图至少存在以下三类视觉标记：

| 类型 | 语义 | 是否允许启动打怪轮询 |
| --- | --- | --- |
| `native_or_uu_orange_dot` | 原生橙色怪物圆点，或 UU 圈动画的实心中间帧 | 只能作为怪物阳性证据之一 |
| `uu_ring_like_orange_marker` | 蓝钻 UU 挂机开启后出现的空心/闪烁圈 | 表示 UU 扫描或锁定提示，不能当作通用原生标记 |
| `resource_marker` | 黄色菱形/四边形采集资源点 | 明确非怪物，禁止计入怪物数量 |

UU 动画的实心阶段和原生怪物圆点单帧外观接近，不能强行做封闭分类。只有连续帧观察到空心圈和实心点交替，才能确认 `uu_target_ring`。

## 后端应采用的输入字段

视觉结果新增/明确以下字段：

```json
{
  "decision_scope": "single_frame_observation",
  "frame_marker_state": "present|absent|unknown",
  "nearby_monster_count": 10,
  "monster_markers": [],
  "uu_target_ring_count": 0,
  "native_or_uu_orange_dot_count": 10,
  "resource_marker_count": 3,
  "resource_markers": []
}
```

`resource_marker_count` 只用于采集系统或地图信息，不得加入 `nearby_monster_count`。

## 后端状态机

1. 每 `150-250ms` 读取一次 L2 小地图结果，送入 `minimap_temporal_fusion.py`。
2. 最近 `1200ms` 内任一怪物阳性帧，允许继续找怪。
3. 单帧 `absent` 和 `unknown` 均为 `noop`，不得停止轮询。
4. 只有至少 5 个连续无怪帧、跨度至少 `800ms`，并且连续 3 次找怪没有获得 `target_panel`，才允许停止轮询。
5. `target_panel` 存在时立即覆盖小地图无点结果。
6. `resource_marker` 永远不能覆盖成怪物阳性。

## 调用位置

- 单帧插槽：`train/artifacts/l2_slots/l2_slot_worker.py --mode minimap`
- 时序融合：`train/artifacts/l2_slots/minimap_temporal_fusion.py`
- 动作规划：`train/artifacts/l2_slots/slot_action_planner.py`

禁止继续直接将单帧 `nearby_monster_present=false` 映射为停止轮询。

## 验收用例

1. UU 圈闪烁：2 帧有圈、3 帧无圈，结果仍为 `present`。
2. 世界画面有怪、小地图边缘无点：不得停止轮询。
3. 剑阁原生地图：橙色圆点计为怪物候选，黄色菱形资源点单独输出。
4. 连续无点但只失败 1-2 次找怪：`noop`。
5. 连续无点约 1 秒且找怪失败 3 次：才输出 `stop_find_monster_polling`。

验证脚本：

- `train/scripts/72_verify_minimap_temporal_edge_cases.py`
- `train/scripts/75_verify_minimap_resource_exclusion.py`
