# ADR-002: 战斗后端抽象

日期：2026-06-21  
状态：Accepted

## 背景

龙伴行第一阶段要先把历史版本的 32 位稳定能力迁移到新前端。自动打怪现在按用户实测和外部仓库调研，拆成三条路线：

1. 自动判断：识别当前场景，野外优先启用游戏内置挂机，副本切换为程序按键打怪。
2. 游戏内置挂机：程序负责开启/监控游戏自带挂机、杀怪数、死亡、坐标和返点，不负责直接打怪循环。
3. 程序按键打怪：程序按秒发送普攻、技能、加血、回蓝、宠物回血、选怪键，适合副本和游戏内置挂机不可用的场景。

三条路线不能写死在 `NormalHangController` 里。控制器只应该表达“什么时候读状态、什么时候回血回蓝、什么时候换怪、什么时候放技能”，不关心状态来自游戏内置挂机监控、程序按键还是图色/OCR增强。

## 决策

战斗后端抽象保留，但语义调整：

- `ICombatBackend`
  - `Read(window, config)`：读取目标、血量、蓝量、宠物血量等战斗快照。
  - `CastHotkey(window, hotkey, config)`：按当前配置释放普攻/技能/回血回蓝快捷键。
  - `TryParseHotkey` / `TryConsumeGlobalCooldown`：复用输入校验和公共 CD。
  - `GetStatus`：返回后端是否可用、实际后端名称和提示信息。

- `ProgramKeyCombatBackend`
  - 程序按键打怪默认后端。
  - 不要求必须识别目标才发技能。
  - 按技能表的秒级间隔发送普攻、伤害、AOE、增益、回血、回蓝、宠物回血、选怪。
  - 技能栏按天龙实际 F1-F10 设计，普通攻击默认 F1，技能默认 F2-F10，不使用 F11/F12。
  - 可叠加图色/OCR增强，但增强失败不能阻断基础按键循环。

- `GameBuiltinCombatBackend`
  - 游戏内置挂机监控后端。
  - 目标是开启/监控游戏自带挂机、读取杀怪数、死亡、坐标、地图/场景、返点条件。
  - 第一阶段先用公开可验证的 `ReadProcessMemory` 状态读取和窗口消息操作做最小实现；旧自有插件链只作为后续可选来源，不作为当前阻塞项。

- `CombatBackendSelector`
  - 根据用户配置选择：自动判断 / 游戏内置挂机 / 程序按键打怪。
  - 自动判断规则：野外场景优先游戏内置挂机；副本或游戏提示无法开启内置挂机时切换程序按键打怪。
  - 后端不可用时必须明确告警并回退到程序按键打怪，而不是静默失败。

`NormalHangController` 只依赖 `ICombatBackendSelector`，不再直接依赖 `ICombatRecognitionService` 或 `IInputService`。

## UI 规则

通用配置首页的“战斗方式”显示为：

- 自动判断
- 游戏内置挂机
- 程序按键打怪

当前版本已经有程序按键打怪雏形，但还不等同于旧版本完整逻辑。下一步必须优先落地游戏内置挂机状态读取和场景判断，解决“野外用内置、副本用程序”的产品分工。

## 边界

1. 当前阶段不引入旧授权链，不引用旧授权组件。
2. 不处理第三方平台、安全组件、风控或反作弊绕过。
3. 32 位状态读取只面向 32 位 `Bin\Game.exe`，不硬转 64 位。
4. 旧自有插件链仅作为后续可选来源；当前优先复用可审计的窗口消息、截图、公开内存读取样例和旧自有配置数据。
5. 外部开源仓库只能作为参考或代码来源审查，不直接吞入未知二进制。

## 验证

`normal-hang` 诊断已覆盖：

- 无目标自动选怪。
- 用户选择的输入通道会被外部后端应用。
- 人物回血、人物回蓝、宠物回血、峨眉加血、技能循环会走战斗后端。
- 红名策略未校准时不攻击普通目标。
- 后端不可用时会产生告警并回退程序按键打怪。

## 外部来源映射

- `talktokim/AutoTLBB`：优先复用窗口枚举、32 位 `ReadProcessMemory` 封装、角色名/HP/MP/坐标/地图 ID 指针链、CE 表，用于 `GameBuiltinCombatBackend` 和 `SceneDetectionService`。
- `sazima/tlbb2`：参考 OpenCV 模板匹配、后台 `PostMessage/SendMessage` 发键、马贼目标判定、队伍头像血量判定、传送寻路模板。不得复用其远端授权/远程 OCR 服务。
- `yfyyyfff/TLBB_AXPPacker_DBEditor`：仅作为离线客户端 `.axp` 静态数据提取工具候选，用于地图/NPC/怪物/场景表导入，不作为运行时组件。
- `XiaBingGame/TLBBModelLoader`：仅用于模型资源研究，不进入 P0。
