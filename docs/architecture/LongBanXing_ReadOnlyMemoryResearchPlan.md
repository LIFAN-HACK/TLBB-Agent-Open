# 龙伴行只读内存研究计划

日期：2026-07-01

## 1. 结论

只读内存可以作为**隔离研究轨道**推进，用来验证人物状态、目标状态、地图、坐标、背包、物品等数据是否能稳定读取。

但它不直接替代现有外部识别链路，也不作为默认启用能力。产品主线仍保持：

- 外部截图识别可独立运行。
- 只读内存可用时作为增强数据源。
- 只读内存不可用时自动降级到 OCR/图色/模板。
- 不写内存、不注入、不 Hook、不绕过第三方安全组件。

## 2. 目标

本计划目标不是“做一个内存外挂”，而是建立一个**只读状态读取层**，为龙伴行提供更稳定的数据输入。

优先读取：

1. 自身人物状态
   - 角色名
   - HP / MaxHP
   - MP / MaxMP
   - 当前地图 / 场景 ID
   - 当前坐标 X/Y
   - 死亡/存活状态

2. 当前目标状态
   - 是否有目标
   - 目标名
   - 目标类型：怪物 / 玩家 / NPC / 召唤物 / 未知
   - HP / MaxHP
   - 距离
   - 是否可攻击

3. 宠物状态
   - 是否出战
   - HP / MaxHP
   - 是否死亡

4. 队伍状态
   - 是否组队
   - 队长标识
   - 队员名称
   - 队员 HP
   - 队员距离或坐标，如果可读

5. 场景对象快照
   - 只读枚举可见对象。
   - 字段仅限：名称、类型、坐标、距离、血量、可交互状态。
   - 用于马贼、反贼、和尚、抢 NPC 的候选发现。

6. 背包/物品状态
   - 背包格占用。
   - 物品 ID / 名称，如果可读。
   - 数量。
   - 绑定状态 / 品质 / 类型，如果可读。

## 3. 禁止项

只读轨道永久禁止：

1. `WriteProcessMemory`
2. 写坐标、写目标、写血量、写状态。
3. DLL 注入。
4. 远程线程。
5. Hook 游戏或第三方安全组件。
6. 绕过安全组件、验证码、风控或反作弊。
7. 修改客户端文件。
8. 修改网络包。
9. 自动隐藏进程、隐藏窗口、隐藏句柄。
10. 为了拿句柄而提升到异常权限或破坏系统保护。

如果读取失败、句柄打开失败、权限不足或客户端版本不匹配，直接降级到外部识别，不做对抗。

## 4. 架构位置

新增独立层：

```text
LongBanXing.App
  -> ViewModel
  -> Controllers
  -> RuntimeStateFacade
      -> VisualRuntimeStateProvider      OCR / 图色 / 模板
      -> ReadOnlyMemoryStateProvider     只读内存，默认关闭
      -> StaticDataProvider              AXP / Lua / XML / 旧数据
```

控制器不直接调用内存读取。控制器只依赖统一结果：

```text
RuntimeSnapshot
  Player
  Target
  Pet
  Team
  Scene
  Inventory
  SourceQuality
```

## 5. 服务设计

### 5.1 `IReadOnlyGameProcessReader`

职责：

- 绑定已授权的 32 位 `Game.exe` 窗口。
- 只读打开进程。
- 校验进程路径、位数、窗口句柄、PID。
- 读取白名单字段。
- 输出结构化快照。

约束：

- 仅 x86。
- 只读。
- 默认关闭。
- 每次读取都必须捕获异常。
- 失败不影响主程序。

### 5.2 `MemorySignatureProfile`

职责：

- 描述某一客户端版本的数据布局。
- 不把偏移散落在业务代码里。
- 支持版本号、文件哈希、时间戳、字段偏移、验证规则。

字段示例：

```text
ClientVersion
GameExeHash
ProfileName
PlayerBase
TargetBase
SceneBase
InventoryBase
Offsets[]
ValidationRules[]
```

### 5.3 `RuntimeStateFacade`

职责：

- 合并外部识别、只读内存、静态数据。
- 给控制器输出稳定状态。
- 内存数据可信时优先使用内存。
- 内存数据缺失时回退视觉识别。
- 多源冲突时保守处理。

示例：

- HP：内存 > 血条图色。
- 坐标：内存 > 小地图 OCR。
- 目标类型：内存 > 目标栏图色。
- 是否玩家：内存类型字段 > 玩家 UI 特征。
- 背包物品名：内存/静态 ID > tooltip OCR > 用户标注。

### 5.4 `MemoryReadDiagnostics`

职责：

- 单独诊断，不接入自动操作。
- 只输出读取到的快照。
- 不发按键、不点击、不执行状态机。
- 生成 JSON 证据。

输出：

```text
artifacts/memory-read/player.json
artifacts/memory-read/target.json
artifacts/memory-read/scene.json
artifacts/memory-read/inventory.json
```

## 6. 研究步骤

### 阶段 A：资料整理

1. 整理已有开源资料。
2. 整理旧工具配置字段。
3. 整理 Lua 里和自动战斗、目标、NPC、DataPool 相关接口。
4. 整理客户端版本号、`Game.exe` 哈希、数据包版本。

产物：

- `docs/research/MemoryResearch_SourceMap.md`
- `data/memory-profiles/source-index.json`

### 阶段 B：只读快照原型

目标：只验证能否稳定读取**自身状态**。

读取范围：

- 角色名
- HP/MP
- 地图/场景
- 坐标

验收：

- 人物站立不动时，连续读取 60 秒稳定。
- 人物移动时，坐标变化和游戏画面一致。
- HP/MP 与界面显示一致。
- 客户端重启后，能通过 profile 重新定位或明确失败。

不做：

- 目标对象。
- 背包。
- NPC。
- 自动操作。

### 阶段 C：目标状态

读取范围：

- 当前目标是否存在。
- 目标名。
- 目标类型。
- 目标 HP/MaxHP。
- 目标距离或坐标。

验收：

- 选中怪物时识别为怪物。
- 选中玩家时识别为玩家。
- 选中宠物/召唤物时不误判为怪物。
- 无目标时稳定返回空目标。
- 与现有视觉玩家判定互相校验。

### 阶段 D：场景对象快照

读取范围：

- 可见对象列表。
- 名称、类型、坐标、距离、HP。

用途：

- 马贼候选。
- 反贼候选。
- 和尚候选。
- 抢 NPC 候选。

验收：

- 对象数量稳定。
- 玩家、NPC、怪物能区分。
- 坐标变化与画面一致。
- 不读取或记录账号敏感数据。

### 阶段 E：背包/物品

读取范围：

- 背包格。
- 物品 ID。
- 数量。
- 绑定/品质/类型，如果可读。

验收：

- 与背包截图 10x6 格子一致。
- 空格/占用格一致。
- 物品 ID 能通过静态物品库映射名称。
- 未知物品仍默认保护。

## 7. 和现有功能的关系

### 7.1 普通挂机

外置按键打怪仍可独立运行。

只读内存可增强：

- 目标是否死亡。
- 是否玩家目标。
- HP/MP 精确值。
- 打死换怪时机。

### 7.2 安全回点

只读内存可增强：

- 地图 ID。
- 坐标。
- 死亡状态。
- 卡点判断。

保守规则：

- 内存地图和 OCR 地图冲突时，不执行跨地图回点。
- 地图未知时，只执行用户明确允许的本地图动作。

### 7.3 马贼/反贼/和尚

只读内存可增强：

- 候选目标发现。
- 目标距离排序。
- 目标类型过滤。

控制仍走外部输入或游戏内置操作，不写内存。

### 7.4 抢 NPC

只读内存可增强：

- 发现目标 NPC 是否进入客户端对象表。
- 快速获得目标坐标。

执行动作仍限制为：

- 客户区点击。
- 交互热键。
- 外部窗口消息。

不做：

- 内部 CALL。
- 写目标。
- 写交互状态。

## 8. UI 设计

新增位置：

```text
数据调试 -> 只读状态
```

显示：

- 当前数据源：外部识别 / 只读内存 / 混合。
- 读取状态：未启用 / 可用 / 失败 / 版本不匹配。
- 当前人物快照。
- 当前目标快照。
- 当前地图坐标。
- 最近 20 个对象快照。
- 背包快照。

开关：

- 启用只读状态增强。
- 只读人物状态。
- 只读目标状态。
- 只读场景对象。
- 只读背包。

默认：

- 全部关闭。
- 用户手动启用。
- 失败自动降级。

## 9. 验收标准

第一验收版本只要求：

1. 能生成只读人物状态快照。
2. 快照 60 秒稳定。
3. 坐标与画面一致。
4. HP/MP 与画面一致。
5. 不影响当前外置打怪。
6. 失败自动降级，不崩溃。
7. 不出现任何写内存、注入、Hook 代码。

第二验收版本：

1. 当前目标类型准确。
2. 玩家目标不攻击。
3. 怪物目标可攻击。
4. 目标死亡换怪更准确。

第三验收版本：

1. 场景对象快照可用。
2. 马贼/反贼/和尚候选可从快照生成。
3. 抢 NPC 可以判断对象是否已出现，但执行仍走外部点击/热键。

## 10. 任务清单

### P0：文档和隔离

1. 新建 `docs/research/MemoryResearch_SourceMap.md`。
2. 新建 `data/memory-profiles/`。
3. 新建 `IReadOnlyGameProcessReader` 接口。

1. 建立 32 位进程只读绑定。

3. 读取人物 HP/MP。
4. 读取地图/坐标。

1. 读取当前目标基础字段。
2. 区分玩家/怪物/NPC/宠物。
3. 接入 `NormalHangController` 的目标安全判定。

### P3：场景对象

1. 读取对象列表。
2. 生成 `SceneObjectSnapshot`。
3. 接入马贼、反贼、和尚、抢 NPC 的候选发现。

### P4：背包物品

1. 读取背包格。
2. 用静态物品库映射物品名。
3. 接入清包候选，但仍默认 DryRun。
