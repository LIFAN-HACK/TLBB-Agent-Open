# 材料加工视觉闭环状态

## 已实现

- V2 定位 `material_panel`。
- V2 安全定位 `manufacture`、`manufacture_all`、`scroll_up`、`scroll_down`、`close`。
- 兼容入口定位器在右侧技能栏内定位材料加工图标；低置信度或多候选时拒绝点击。
- 点击入口后等待新帧，并以 V2 再次确认材料面板已经打开。
- 配方区固定分为五行，每行使用 L2 多裁剪识别；必须 5/5 可靠才允许继续。
- 配方名作为页面指纹，滚动后按名称去重，重叠行不会重复加工。
- 每个配方选择后持续点击“全部制造”，直到 L2 连续两帧确认材料或活力耗尽。
- 识别到“正在制造/正在加工”后只等待新帧，不重复点击；状态结束后才允许下一次制造动作。
- 页面指纹连续两次不变时判定滚动到底；只有至少一个配方完成耗尽确认后才允许结束。
- 未确认面板、按钮、配方行、L2 终止提示或安全策略时禁止点击或完成。
- 达到安全时限但没有终止证据时停止，不标记完成。
- 正式功能键统一为 `hang.material`；左侧当前窗口启动区可解析到材料控制器。
- 材料页面状态绑定真实控制器，不再固定显示“未就绪”。

## 已验证

- 跨日期入口定位：`800x600 -> (763,228,30,30)`、`2576x1408 -> (2531,578,30,30)`，生产定位器 NCC 均为 `1.000000`。
- 两天共 186 张杂项截图扫描得到 130 个高置信候选，候选集中在对应分辨率的右侧技能栏位置。
- 真实材料面板配方识别：5/5，分别为铸造碎片、低级铸铁、高级铸铁、缝纫布片、中级布片配方。
- V2 滚动动作规划：`scroll_down -> Click@1391,496`。
- 合成多页回归：重叠配方去重，三配方各加工一次，滚动三次，共九次安全点击。
- 加工中时序回归：两帧加工中后两帧材料不足，整个过程仅执行一次制造点击。
- 编码协议统一为 UTF-8/ASCII JSON 转义，中文 OCR 文本不会再使规划器退化为空动作。

## 尚未完成的现场证据

- 入口模板已通过两个采集日期和两种分辨率回归；仍需人工复核相似生活技能负样本。
- 尚缺真实“材料不足”“活力不足”“加工中”“加工完成”提示帧。
- 尚未在真实游戏窗口执行全配方点击验收；当前仅完成真实帧只读识别与合成动作回归。
- 若真实列表底部不足五个可见配方，当前会安全停止，需要采集该界面后增加空行判定。
