# ADR-004：视觉模型本地与云端部署策略

日期：2026-07-11  
状态：已采纳（P0 默认本地，云端保持实验能力）

## 1. 决策

1. 实时战斗、目标生死、玩家保护、技能 CD 和点击安全门默认在本地运行。
2. 保留完整云端推理协议和可部署服务，用于真实云主机性能、成本和稳定性测试。
3. 云端响应不能直接驱动输入。所有点击建议必须由本地校验帧序号、截图哈希、模型哈希、时效、置信度、动作白名单和客户区边界。
4. 后续优先评估混合模式：本地 L1 定位和脱敏，只上传必要裁剪给云端 L2；不优先上传完整游戏画面。
5. 真实云端通过验收前，不把云端模式接入默认运行配置。

## 2. 三种部署形态

### 2.1 全本地

```text
客户区截图 -> 本地 L1 -> 本地 L2 -> 本地策略 -> 本地安全门 -> 输入服务
```

优点：无网络抖动、隐私最好、断网可用、动作时效最容易保证。  
缺点：模型资产随客户端分发，存在提取风险；用户硬件性能差异大；升级模型需要发版或增量更新。

### 2.2 全云端

```text
客户区截图 -> 编码/签名 -> HTTPS 上传 -> 云端 L1/L2
           <- 签名感知结果/坐标建议 <-
           -> 本地安全门 -> 输入服务
```

优点：模型不落用户机器；模型和推理环境可统一升级；便于质量监控。  
缺点：完整截图包含角色名、聊天、背包等敏感信息；上传带宽与 RTT 直接进入动作延迟；断网或服务故障会中断；服务端被攻破时会产生恶意动作建议风险。

### 2.3 混合模式（推荐后续验证）

```text
客户区截图 -> 本地 L1/脱敏/裁剪 -> 云端 L2 重模型
           <- 结构化感知结果 <- 本地策略与安全门 -> 输入服务
```

保留本地实时性和最终执行权，只把确实需要云端算力的目标名称、复杂面板或开放词表裁剪上传。

## 3. 已落地的安全边界

- 请求与响应均使用 HMAC-SHA256 签名。
- 请求包含时间戳与一次性 nonce，服务端拒绝过期和重放请求。
- 上传内容使用 SHA256 绑定请求；响应再次绑定原请求 ID、会话 ID、帧序号与截图哈希。
- 本地固定允许的模型 SHA256，拒绝服务端静默切换未知模型。
- 单帧最多允许一个点击建议；非 `Click/Noop` 动作不能直达执行器。
- 点击建议低于 0.80 置信度、已经过期或超出当前客户区时拒绝。
- 感知结果与动作建议使用不同安全时效；低频识别结果可以保留数秒，点击建议必须使用更短的独立过期时间。
- 云端服务不把截图写入业务日志；响应设置 `no-store`。
- 非本机客户端拒绝明文 HTTP 端点，必须使用 HTTPS。

实现：

- `VisionRemoteProtocol` / `VisionRemoteInferenceResponse`
- `VisionRemoteResponseSafetyGate`
- `TlbbAgent.VisionDeploymentHarness`

## 4. 生产上线前仍需补充

当前 HMAC 共享密钥适合内测，不是最终账号认证方案。正式云端至少还需要：

1. TLS 1.3 与证书校验，禁止忽略证书错误。
2. 短期访问令牌，避免把长期共享密钥固化进客户端。
3. 每设备/账号限流、并发限制、请求体大小限制和异常封禁。
4. 服务端截图零留存策略、临时文件隔离、日志字段白名单和审计记录。
5. 多租户隔离，禁止跨会话复用截图、状态或动作。
6. 服务不可用时本地降级，不缓存和补发过期点击。
7. 云端返回感知结果而非最终业务命令；本地策略层保持独立。

## 5. 当前结论

当前 2560×1369 全帧测试显示，PNG 上传体积和网络耗时不适合战斗闭环；JPEG 能明显减小体积，但会引入轻微视觉数值漂移。P0 因此继续使用本地模型。云端服务保留用于真实硬件对比和非实时插槽实验，混合裁剪方案作为下一阶段优先验证项。
