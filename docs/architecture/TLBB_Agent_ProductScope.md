## 2. 核心定位

> 现代化前端 + 复用旧龙伴行成熟后端逻辑 + 统一配置 + 统一状态机 + 统一字库识别 + 统一按键 + 统一日志。

第一阶段形态：**32 位稳定版龙伴行功能整合客户端**。

---

## 3. 它是什么

1. 一个**新的**、现代化前端的 Windows 桌面自动化客户端。
2. 后端**复用** 历史版本 及授权数据目录中成熟模块的**数据与流程蓝本**（字库、坐标、配置、题库、状态机），在新后端重写。
3. 统一窗口绑定、配置系统、字库/模板识别、按键服务、状态机、日志。
4. 移除龙伴行自有登录链路认证，启动直达主界面。
5. 整合授权数据目录中**择优**后的模块能力（非无差别合并）。

## 4. 它不是什么

1. ❌ 不是旧 UI 翻新 / 换皮。
2. ❌ 不是 EXE patch / crack 工具。
3. ❌ 不是 64 位内存研究项目（一期）。
4. ❌ 不是单功能挂机脚本。
5. ❌ 不是把多个历史执行文件 当黑盒打包到一起。
6. ❌ 不绕过任何第三方游戏/平台/安全/反作弊机制。

---

## 5. 范围边界

### 5.1 处理对象（自有）
龙伴行自有：软件、历史客户端、授权数据、代码、配置、资源（`本机授权数据目录` 及 历史版本 运行态释放物）。

### 5.2 允许的动作
源码/静态分析、数据解包、功能迁移、重构、UI/UX 重构、**自有**登录链路认证移除、新项目搭建、功能整合。

### 5.3 禁止
第三方游戏登录/账号/安全组件/反作弊/验证码/风控绕过；直接 patch 原始样本；修改授权数据/`C:\sys` 原始文件；明文存账号密码。

## 6. 阶段功能范围

### 第一阶段 P0（32 位）
1. 窗口绑定
2. 按键打怪
3. 挂机返点
4. 马贼模式
5. 抢 NPC
6. 自动反贼
7. 自动和尚
8. 自动三环

### 第二阶段 P1
1. 跑商 2. 材料加工 3. 挖矿 4. 挖图 5. 单师门 6. 帮贡 7. 答题题库 8. 其他授权模块优秀功能

### 暂缓/预留
- 盟会采集：**仅前端预留**，不做正式执行逻辑（怀旧服未开放）。
- 64 位完整功能：二期。

## 7. 统一能力层（9 大服务）

| 服务 | 职责一句话 |
|---|---|
| AppInitService | 本地目录/配置/日志/字库/插件初始化，**无远端登录** |
| WindowBindingService | 拖拽绑定、句柄/PID/标题/路径、32/64 位判定、绑定状态 |
| WindowCaptureService | 窗口/客户区/区域/头像截图，生成 OCR 输入图 |
| TemplateOcrService | 接入 aj.txt 类字库，固定文字/怪名/NPC/地图/状态识别 |
| InputService | 按键/点击、PostMessage/SendInput、技能快捷键、公共 CD、间隔 |
| StateMachineEngine | 各模式独立状态机（挂机/马贼/抢/反贼/和尚/三环/跑商/采集/任务） |
| ProfileConfigService | 命名/保存/加载/导入导出/版本迁移/备份，按角色/窗口/模式 |
| RuntimeLogService | 运行/错误/模块/状态机日志，可复制/导出/过滤 |
| LegacyDataAdapter | 从 历史版本 及各模块导入数据、统一格式、标记来源、迁移日志 |

---

## 8. 验收锚点（第一阶段）

- 启动无登录链路界面，直达主界面。
- 可拖拽绑定并识别 32 位 `Game.exe`，展示窗口信息与位数。
- 可命名保存/加载配置。
- P0 八大功能均可配置并启动，状态机有可视日志。
- 每个接入数据有来源说明；每个登录链路依赖有处理说明。
- 未完成功能在 UI 明确标注（未接入/部分接入/已接入/运行中/错误），不伪装完成。
