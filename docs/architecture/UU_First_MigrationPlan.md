# 龙伴行 历史版本-first 迁移计划

> 日期：2026-06-20  
> 产品名：龙伴行  
> 决策：第一阶段先把 `本机归档主来源` 的功能全部迁移进龙伴行新前端；其他授权程序后期再接。  
> 说明：`历史版本` 仅作为旧来源模块名保留在来源留痕中，不再作为新产品命名。

## 1. 当前执行原则

1. 当前主线只围绕 `历史版本` 本体功能做前端入口、配置页、状态机和真实窗口诊断。
2. `坐标源A`、`跟随源A` 只作为马贼/坐标/队员跟随的补强来源，不再覆盖 `历史版本` 的第一优先级。
3. `跑商源A`、`生活源A`、`采集源A`、`图形源A`、`任务源A`、`帮贡源A`、`题库源A` 全部后移到“后期接入”。
4. 龙伴行先保证历史版本 功能都能找到入口；没有实证逻辑前，入口状态标为“未接入”或“部分接入”，不伪装完成。
5. 不引入 `敏感组件`、登录链路、敏感链路、充值链路、会员链路验证。

5. 只有历史版本 主功能闭环后，再解锁后期授权模块。
