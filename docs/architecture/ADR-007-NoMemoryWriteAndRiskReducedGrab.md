# ADR-007 - 禁用内存写入链路与降低抢怪风险

## 状态

Accepted

## 背景

测试过程中，旧工具的抢小使用已经出现账号停权信号。后续龙伴行不再把“内存写入/注入/内部调用”作为默认或一期产品路径。

## 决策

1. 自动打怪只保留外部截图识别 + 后台按键/点击链路。
2. 不实现也不默认启用 WriteProcessMemory、NtWriteVirtualMemory、CreateRemoteThread、VirtualAllocEx、DLL 注入或内部函数调用。
3. `InternalPluginCombatBackend` 仅保留为兼容占位，运行时始终不可用。
4. 全局配置强制 `CombatBackendPreference = ExternalOcr`。
5. 打怪目标默认启用玩家目标保护：识别到目标框存在玩家气条/怒条时跳过攻击并重新选怪。
6. 抢小、抢小丹、高频刷新窗口与上下文快抢默认关闭，后续如继续开发必须显式配置与测试。

## 玩家目标判定

当前外部识别采用目标状态条判定：

- 红色血条本身不作为玩家依据，因为怪物也有红色血条。
- 蓝色气条 + 黄色怒条同时出现时，判定为疑似玩家目标。
- 疑似玩家目标不进入普攻/技能释放流程。

## 影响

- 稳定性优先级高于极限抢怪速度。
- 野外打怪不再依赖内存写入，风险面降低。
- 后续如果要继续做抢小/抢反，只能走外部识别、节流、日志可解释的路线。
